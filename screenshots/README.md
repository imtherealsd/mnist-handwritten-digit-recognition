# Project Screenshots Guide

This directory is intended to store genuine screenshots of your model training, evaluation, and interactive Streamlit web application for your **Horizon Intern Machine Learning Internship** submission.

> **Important**: Never use fake or fabricated screenshots. Capture genuine screenshots from your local execution or Google Colab session following the checklist below.

---

## Required Screenshots Checklist

| File Name | Description | Where to Capture |
| :--- | :--- | :--- |
| `01_colab_training.png` | Google Colab notebook displaying dataset loading, CNN architecture summary, and training progress. | Google Colab |
| `02_evaluation_matrix.png` | Test set evaluation, Confusion Matrix heatmap, and per-digit Classification Report (Precision, Recall, F1-Score). | Colab or Terminal |
| `03_streamlit_overview.png` | Streamlit web application homepage showing header, drawing canvas, and sidebar with CNN architecture notes. | `http://localhost:8501` |
| `04_canvas_prediction_high_conf.png` | Interactive prediction of a user-drawn digit (e.g., `7`, `3`, or `8`) showing the preprocessed 28×28 view, predicted digit card, confidence score (>90%), and probability bar chart. | `http://localhost:8501` |
| `05_image_upload_test.png` | Testing an uploaded image of a handwritten digit via the "Upload Digit Image" tab, demonstrating auto-inversion and prediction. | `http://localhost:8501` |

---

## How to Capture High-Quality Screenshots

1. **Browser Zoom**: Set browser zoom to 100% for crisp typography and alignment.
2. **Clear Canvas**: Ensure the canvas and the 28×28 "Model Perception" box are clearly visible alongside the prediction cards.
3. **Window Focus**: Crop the screenshot to focus on the application content (avoid clutter from unrelated browser tabs or desktop icons).
4. **Naming**: Save files using the exact filenames listed above in this `screenshots/` directory.
